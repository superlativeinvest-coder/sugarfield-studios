# Pokopia Printable Visual Guidelines — P06 First

This is the canonical visual standard for future Sugarfield Studio Pokopia printable customer assets.

## Reference priority

1. Approved P06 Pokopia Daily Reset artwork — dominant reference
2. Approved P13 Event Tracker artwork — secondary structural reference only
3. Approved Quick Start artwork — tertiary family-consistency reference

When references differ, P06 controls the decision.

## Locked P06 visual language

- Warm cream/off-white printable background.
- Large multicolor Pokopia logo or equivalent multicolor title hierarchy at the top.
- Light cream header composition with botanical accents and restrained mascot placement.
- Do not substitute a dark P13-style banner as the primary header treatment.
- Lavender ornamental page border with rounded corner details.
- Numbered section-card structure where the page content supports it.
- Soft watercolor/pastel section bands rather than compact generic label tabs.
- Lavender, sky-blue, mint/green, and warm-gold sections used as a balanced system.
- Original line-art icons may support section headers or checklist rows, but never obstruct writing areas.
- Generous handwriting space, clear section hierarchy, and readable body text at 100% print size.
- P06-style footer ordering, disclaimer treatment, and page-number capsule.
- Decorative art remains secondary to worksheet usability.

## Composition rules

- The page should feel like it belongs beside P06 at thumbnail size before detailed inspection.
- Header, title hierarchy, panel geometry, section bands, mascot treatment, spacing, density, footer, and page capsule must all be compared against P06.
- P13 may inform functional organization, but a page must not visually read as a P13 redesign.
- Every writing panel, checklist row, table cell, blank line, and status field must remain blank and unobstructed.
- Do not add official logos, official screenshots, official UI, official character art, watermarks, or invented gameplay claims.

## Required approval gate

Future Pokopia printable pages pass only when all of these are true:

- P06-style header and title hierarchy: PASS
- P06-style mascot/decorative treatment: PASS
- P06-style section bands and panel geometry: PASS
- P06-style spacing and density: PASS
- P06-style footer and page capsule: PASS
- P06-first visual impression at thumbnail size: PASS
- No P13-led dark-banner substitution: PASS
- Writable areas remain blank and usable: PASS

Any failed visual gate requires regeneration of the affected page before PDF assembly. Visible text must never be repaired with overlays, HTML, SVG, Pillow, ReportLab, or manual raster editing.

## Current P16 note

The existing P16 Adventure Dashboard artwork was created before this guideline was formalized. Its dark banner/header treatment is P13-led and requires a future visual-consistency regeneration. Existing artwork and PDFs remain untouched until that targeted regeneration is separately authorized.
