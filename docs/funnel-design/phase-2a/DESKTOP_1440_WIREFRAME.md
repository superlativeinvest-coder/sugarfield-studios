## Dimensions and hierarchy

- Page shell: 1,160px max content width; 24px outer desktop gutter minimum.
- Header: 76px high; recovery is a quiet text link, not a second primary CTA.
- Hero: 680px visual minimum; 1:1 two-column grid with 64px gap.
- Copy column: 520–600px; H1 64–78px; lede 19px; facts 11px; label 12px.
- Form: 530px maximum, 56px input/button height; button remains adjacent to input at 1440px.
- Hero visual: approved P01 primary page with P02/P03 support pages; no fabricated seventh-page imagery.
- Sections: 86px vertical padding; cards have 16–18px gaps; footer remains compact.
