# Customer Psychology and Value Proposition

## Verified offer truth

The verified offer is a free seven-page printable Quick Start Pack in US Letter and A4 (`data/pokopia-funnel.ts`, `lib/quick-start/manifest.ts`). Its supported uses are session goals, daily priorities, island sketching, rare-finds notes, and weekly planning. No ratings, testimonials, outcomes, scarcity, or download statistics are available for use.

## Proposed decision model

1. A visitor needs to recognize that the guide helps organize a Pokopia session.
2. They need to see that it is a real, useful printable rather than a generic lead magnet.
3. They need a low-friction, trustworthy path to claim it.
4. Existing claimants need a secondary path to restore access without competing with first-time signup.

### Primary value proposition

**A free, practical printable pack that helps a Pokopia player choose a focus, remember daily priorities, and save ideas for the next session.**

### Objection handling

| Uncertainty | Supported response |
| --- | --- |
| “What is this?” | Free seven-page Pokopia printable pack. |
| “Will I actually use it?” | Show approved Dashboard, Daily Reset, next-step, sketch, and rare-finds pages. |
| “Is this really free?” | “Free to claim. No card or password required.” |
| “What format is it?” | US Letter and A4 PDFs. |
| “I claimed it already.” | Header recovery anchor and dedicated existing-access panel. |

## Attribution hypotheses

- **TikTok:** visitors may need immediate visual proof and a short benefit-led message. This is a hypothesis to test, not a proven performance claim.
- **Pinterest:** visitors may arrive with stronger interest in printable planning and may value close-up page readability. This is a hypothesis to test, not a proven performance claim.
- Both sources receive the same accurate offer, analytics semantics, privacy controls, and access flow.

## Approval requirement

Approve the value proposition and objection language before Phase 2B. Do not claim email-delivery timing until the separate provider verification is complete.
